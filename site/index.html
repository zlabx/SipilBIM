SipilBIM

Pemodel 3D gratis untuk arsitektur dan teknik sipil: gambar dan tarik bentuk seperti menggambar tangan, lalu beri label BIM dan keluarkan kuantitas IFC.

Unduh installer Windows
Build ini belum ditandatangani. Windows SmartScreen bisa menampilkan peringatan saat pertama kali dijalankan: pilih More info, lalu Run anyway. Jika muncul galat Failed to load python312.dll, pasang Visual C++ Redistributable dari Microsoft.

Yang bisa dilakukan

Menggambar, extrude, mengedit, mewarnai, memberi dimensi dan anotasi; membuka berkas .skp; mengimpor DXF dan data survei; memberi label kelas BIM dan mengekspor kuantitas IFC.
